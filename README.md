# TRACE

TRACE is an evidence-based hiring platform designed to help recruiters evaluate and rank candidates based on their skills, qualifications, and supporting evidence.

Instead of relying solely on traditional resumes, TRACE aims to provide recruiters with a clearer picture of what candidates can actually demonstrate.

## Planned Features

- Candidate profiles
- Resume and portfolio information
- Skills and qualifications
- Evidence of demonstrated skills
- Job postings
- Candidate screening and ranking
- AI-assisted candidate evaluation

## Initial Planned Stack

- React
- Vite
- Tailwind CSS
- Node.js
- PostgreSQL
